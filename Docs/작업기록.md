## 0. 기준
- **실제 게임 기준으로 개선**: 시즌1 기획안과 다른 점은 개선점으로 세지 않음(기획안대로 안 만든 부분이 많음).
- **기존 프로젝트는 건드리지 않음**: 시즌1(ObstacleCourse)은 원래대로 두고, 이 새 프로젝트(Unity 6000.6.8f1)에서 작업.
- **유니티 안에서 만듦**: 맵 · 모델 · 텍스처 · 메시를 외부 툴 없이 에디터 스크립트로 생성(hera-agent-unity로 에디터를 조작 · 확인).

## 1. 만든 것 (현재 상태)
### 실행 방법
1. 에디터 메뉴 **Chicken Fly ▸ Project Setup** (태그 · 중력 -20 · 입력 Both, 처음 한 번)
2. **Chicken Fly ▸ Build Chicken Model** (닭 모델)
3. **Chicken Fly ▸ Build World (10 Stages)** → `Assets/Scenes/ChickenFly_World.unity` 생성
4. 숫자 조절: `Assets/Settings/ChickenFly/StageBuildSettings.asset`(맵 · 난이도 · 카메라), `Assets/Resources/FX/FeedbackSettings.asset`(이펙트)

### 게임 구조
- 시즌1처럼 **처음부터 끝까지 이어진 한 맵**: 길이 2,985m, 바닥 높이 0 → 569m. 10스테이지 = 맵 안의 구간.
- 길은 올라가면서 **구간마다 왼쪽 · 오른쪽으로 꺾임**(시즌1 구조), 구간마다 **폭 · 높이가 다름**(넓은 곳 = 자유 비행, 구름 구간 = 좁은 통로가 난이도).
- W를 계속 누르면 **최고 30m/s까지 계속 빨라짐**(기본 10m/s의 3배), 빨라질수록 시야 · 카메라 · 바람 줄로 속도감.
- 구간 진입 시 화면 위 "STAGE N" 배너, 구간 시작마다 체크포인트(둥지와 알).
- 하늘 · 안개 · 빛 · 후처리가 구간 사이 60m 동안 섞임(시즌1 벽 색 하늘1 → 하늘5처럼 위로 갈수록 짙어짐).
- 난이도 곡선: 1 → 6 상승, 7 · 8은 "어려워 보이지만 한 길만 따라가면 다 피해지는" 숨 고르기, 9 · 10은 6보다 높음.

### 조작 · 게임 감각
- W 전진 / S 브레이크 · 후진 / 마우스 방향 / Space 날갯짓(jumpForce 13). A/D 제거.
- 수평 속도 직접 처리(최고 10m/s, W를 떼면 약 1.4초에 멈춤, 옆 미끄러짐 없음).
- 체크포인트 부활(0.5초 정지, 반전 상태 기억), 사망 횟수 · 누적 시간 · 최고 기록(PlayerPrefs).
- 사망: 히트스톱 0.08초 → 깃털 · 불꽃 → 부딪힌 물체 깜빡임 → 1초 뒤 부활.
- 이펙트 강도는 '이룬 일의 크기'에 맞춤: 날갯짓(작게) < 부스트 < 체크포인트 < 클리어(색종이).
- 조작 잠금 0.3초 이하 + 입력 버퍼 0.15초(hera 게임필 지식 베이스 control lock budget · input forgiveness 기준).
- 맵 밖 방지: 앞뒤 바위 바리케이드 · 양옆 · 위 보이지 않는 막(두께 4m, 겹침 4m) · 위쪽 바람 띠 · 바깥 감시(StageBounds) · 연속 충돌 검사.

### 닭
- 유니티 기본 도형으로 새 모델(통통한 몸, 크림색 배, 볏, 부리, 큰 눈, 볼터치, 둥근 깃털 날개, 꽁지 부채, 발가락 3개). 시즌1 색(흰 몸 · 노란 날개 · 주황 부리).
- ChickenAnimator: 날갯짓 내려치기 + squash/stretch + 다리 차기, 날 때 다리 동동 · 날개 파르르, 낙하 때 허둥지둥, 속도만큼 기울기, 머리 까딱, 눈 깜빡, 서 있을 때 꼼지락.
- 충돌은 몸통 상자 하나(날개 · 다리 끝 스침은 안 죽음).
