# Can Chicken Fly? 기획 결정 (2026-11-12)
Chickens Fly Too(앞으로 날아가는 10구간)와 같은 프로젝트에 새 씬으로 만드는 **수직 등반 게임**입니다.
아래는 질문 4회로 정한 내용입니다. **숫자는 초기값**이고, 직접 플레이하며 조절합니다(값은 인스펙터 · 설정 에셋으로 뺍니다).

## 0. 참고 게임에서 가져오는 것
| 참고 | 가져오는 것 |
|---|---|
| 온리업(Only Up!) | 3D 3인칭, WASD = 카메라 기준 이동, 마우스 = 카메라만 회전(닭은 움직이는 쪽으로 몸을 돌림), 순간이동 없는 진짜 낙하, 탑처럼 쌓인 맵이라 떨어지면 아래 구간에 걸림 |
| 겟투워크(Get To Work) · 점프킹 | 정해진 물체에 안착하며 올라가기, 꾹 눌러 충전하는 점프(온리업 점프는 충전이 없음) |
| 우리 게임만의 것 | 닭다운 비행: 날아올라 파닥임 → 힘이 줄며 활공 → 낙하 |

## 1. 조작
| 입력 | 동작 | 초기값 |
|---|---|---|
| 마우스 | **FPS처럼 돌린 만큼 닭이 그쪽을 봄**(몸 방향 = 카메라 방향, 2026-11-12 변경) | 거리 8m(휠로 3.5~16), 벽에 가리면 당겨짐 |
| WASD | 닭 기준 앞 · 뒤 · 옆걸음 | 땅 속도 6m/s |
| Space 꾹 | 충전: 제자리에 멈춰 웅크림(납작 · 날개 모음), 게이지 표시 | 최대 **1.5초** |
| Space 뗌 | 날아오름: 위로 + 누르고 있던 WASD 쪽으로 살짝 기울어 | 꽉 충전 = 최고 **약 12m**, 톡 = 약 1.5m |
| 공중 WASD | 땅의 **70%** 힘으로 방향 조절 | |
| 공중 Space 꾹 | **누르는 동안만 활공**(천천히 떨어짐), 떼면 바로 떨어짐. 활공 힘은 점점 줄어듦 | 활공 최대 약 2초, 착지하면 다시 참 |

비행 순서(자동): 날아오름 → 파닥이며 상승(받은 힘이 점점 줄어듦) → 정점 → (Space를 누르면 활공 / 안 누르면 낙하)

## 2. 안착 · 충돌 · 낙하
- **모든 물체에 설 수 있음**(조작만 잘하면). 별도의 '안착 전용 표시'는 없음.
- **기울기에 따라 미끄러짐**: 완만하면 그대로 서고, 가파를수록 천천히 → 빠르게 미끄러짐. 미끄러지는 중에도 WASD · 충전 점프로 버틸 수 있음.
- **모서리**: 발이 모서리에 반쯤 걸리면 바깥쪽으로 약간 미끄러짐.
- **부딪힘**: 벽 · 발판 옆면에 부딪히면 튕겨 나감.
- **낙하 속도가 클수록 크게 영향**: 많이 떨어질수록 빨라지고(중력 24m/s², 최고 40m/s), 17m/s(≈ 6m 낙하)보다 세게 부딪히면 튕기고 앞으로 미끄러짐. 세게 부딪힐수록 더 높이 튕기고 더 멀리 미끄러짐.
- **구르기**: 아주 세게 부딪혔을 때만(34m/s 이상 ≈ 25m 넘게 낙하) 데굴데굴 구르며 약 1초 조작 불가.
- **바람**: 공중에서는 그대로, 땅에 서 있을 때는 25%만 받음(발로 버팀).
- **떨어지면 진짜로 떨어짐**: 순간이동 없음. 아래 발판에 걸리면 거기서 다시, 큰 실수면 여러 구간을 지나 아래로. 일부러 떨어지는 길(낙하 통로)을 맵에 설계.
- **장애물(새 · 번개 · 바람 · 우박 등)**: 죽지 않음. 닿으면 밀려나고 날갯짓 · 활공이 끊겨 떨어짐(번개는 감전 연출 + 깃털).

## 3. 세이브
- **체크포인트 3개**(드물게): ① 4구간 절벽 시작 ② 7구간 구름 시작 ③ 10구간 대기권 시작.
- 체크포인트를 지난 뒤 그 높이보다 20m 넘게 떨어지면 깃털이 흩날리며 그 체크포인트 둥지로 돌아옴. 그 위에서 떨어지는 손해는 그대로.
- 게임을 끄고 켜면 마지막에 서 있던 자리에서 이어 함(위치 자동 저장).

## 4. 맵
- 높이 **2000m**, **12구간 전부** 이번에 만듦. 목표: **숙련자가 한 번에 약 30분**(최종 1~2시간으로 늘릴 때는 위로 이어 붙임).
- 코스 전체 경사 **70~80°**: 옆으로 1 갈 때 위로 3.5~5 올라감. 길이 중심축 주변을 감으며 올라가서, 떨어지면 아래 구간 위로 떨어짐(온리업 구조).
- 난이도는 **발판 모양 · 크기 · 간격 · 기믹**으로 조절.

### 4-1. 만든 결과(2026-11-12 첫 생성)
- 발판 약 360개(구간 시작 쉼터 · 이어 주는 발판 포함), 꼭대기 2000m 작은 행성 위 금빛 알 둥지.
- 난이도 값(1 ~ 10): 2 · 2.8 · 3.5 · 4.3 · 5.2 · 6.2 · **4.5 · 5.2**(7 · 8 숨 고르기) · 7.2 · 8.2 · 9.1 · 10.
- 범위("처음이 너무 쉬움, 발판이 크고 낮음" 피드백 반영): 발판 반폭 쉬움 1.6~2.4m · 어려움 0.9~1.5m, 높이 차 쉬움 3~6m · 어려움 5.5~10m, 간격 쉬움 1.2~3.2m · 어려움 3~7m. 쉼터는 6~10칸마다.
- 기둥: 닭장 가운데 사일로(52m) → 닭장 옆 풀 언덕(0~180m, 꼭대기 = 숲 시작 쉼터) → 언덕 위 거대한 나무 줄기 → 나무 위로 솟은 절벽 → 눈 덮인 봉우리. 하늘부터는 기둥 없이 나선.
- **길 안내(자연스럽게)**: 길이 되는 발판에만 빛나는 옥수수 알갱이(모이) + 위로 피어오르는 금빛 반짝임. 장식(밟을 수 없는 구름 · 섬)에는 없음. 구간 시작 쉼터에는 나무 표지판(구간 번호 · 이름).
- 체크포인트: 4구간 · 7구간 · 10구간 시작 쉼터의 둥지와 알.
